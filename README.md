# Inglês

Páginas de prática de inglês (fala por microfone). Site: GitHub Pages.

- `index.html`: menu
- `palavras.html`: cards de palavras
- `aulas/aula-NN-frases.html`: frases de cada aula

Cada página é um arquivo único, sem build. Para uma aula nova: coloque o arquivo em `aulas/`, adicione o link no `index.html` e faça push.
